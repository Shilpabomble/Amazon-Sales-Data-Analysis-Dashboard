# Amazon-Sales-Data-Analysis-Dashboard
Amazon Sales &amp; Order Analysis dashboard built in Tableau to explore sales performance, order trends, sales channels, order priorities, and cost patterns. Includes interactive KPIs, filters, and visualizations to transform raw data into meaningful business insights.

# 📊 Amazon Sales & Profit Analysis Dashboard | Tableau

## 📌 About the Project

This project is an interactive **Amazon Sales & Profit Analysis Dashboard** built using **Tableau**.

The goal was to analyze Amazon sales data and understand business performance across **sales channels, order priorities, years, regions, and countries**.

I transformed the raw sales data into meaningful visualizations and KPIs to make business performance easier to understand.

---

## 🎯 Key Objectives

- Analyze overall sales and profit performance
- Compare Online and Offline sales
- Understand yearly order trends
- Analyze orders by priority
- Identify profitable regions and countries
- Track revenue, profit, units sold, and shipment performance
- Build an interactive and easy-to-understand Tableau dashboard

---

## 📊 Key KPIs

The dashboard tracks:

- **Total Profit:** $797M
- **Total Revenue:** $2.41B
- **Units Sold:** 9.1M
- **Average Shipment Days:** 24

---

## 📈 Dashboard Highlights

### Amazon Sales & Order Analysis

- Revenue by Sales Channel

### Amazon Sales & Profit Dashboard

- Profit by Region
- Profit by Country
- Total Profit
- Total Revenue
- Units Sold
- Average Shipment Days

The dashboard also includes **interactive navigation and visual analysis** to explore different aspects of the data.

---

## 💡 Key Insights

- **Offline** sales generated higher revenue than Online sales.
- **2012** recorded the highest number of orders.
- **High-priority** orders had the highest order volume.
- **Sub-Saharan Africa** generated the highest profit among the displayed regions.
- The dashboard shows clear changes in **orders and costs across different years**.
